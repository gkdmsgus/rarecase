# Clinical Checkpoint 논문 — 학회 양식 변환 기록

작성 2026-09-16.

## 무엇을 만들었나
사용자가 전달한 `Clinical_Checkpoint_논문_한글열기용.docx`는 **텍스트가 없고 논문 2쪽을 이미지로 담은 파일**이었다.
그 안의 본문을 읽어, 참고 양식(`논문_CMM_검토_20251016.pdf`, 한국실천공학교육학회 학술발표대회 논문집)에 맞춰 다시 조판했다.

| 파일 | 내용 |
|---|---|
| `docs/Clinical_Checkpoint_paper.docx` | 제출용 원고 (2쪽, 2단) |
| `docs/Clinical_Checkpoint_paper.pdf` | 확인용 변환본 |
| `tools/build-paper-docx.py` | 원고 생성 스크립트 (본문 텍스트가 여기 있다) |
| `docs/figures/architecture.png` | 그림 1. 시스템 구성과 생성형 AI 역할 범위 (새로 그림) |
| `docs/figures/ui-history.png` | 그림 2. 가상환자 문진 화면 (원본 쪽 이미지에서 잘라냄) |
| `docs/figures/ui-imaging.png` | 그림 3. 합성 교육용 CT 관찰 화면 (〃) |
| `docs/figures/figure1-history.png`, `figure2-imaging.png` | 원본 논문 1·2쪽 이미지 (출처 보관용) |

다시 만들려면:

```bash
python tools/build-paper-docx.py
```

## 양식 대조
- 2쪽, 본문 2단, 제목 블록은 1단 — 참고 양식과 동일
- 국문 제목 → 저자·소속·이메일 → 영문 제목·저자·소속 → 요 약 → Key Words → Ⅰ 서론 → Ⅱ 본론 → Ⅲ 기대효과 및 검증 계획 → Ⅳ 결론 → 참고문헌
- 본문 9pt, 그림 캡션 8.5pt, 참고문헌 8pt (2쪽에 맞추기 위해 조정한 값)

## 원본에서 바뀐 것
- 절 번호를 참고 양식에 맞춰 Ⅰ~Ⅳ와 본론 하위 번호로 재배치했다. 문장은 원본을 유지했다.
- 그림 순서: 시스템 구성도를 그림 1로 앞세우고, 화면 캡처를 그림 2·3으로 두었다.
- 표 1은 열 너비를 고정했다(변환 과정에서 세 번째 열이 잘리는 문제가 있었다).

## 확인 필요
1. 학회·연도·Vol/No (2쪽 머리글), 제출 형식·마감·분량 제한
2. 저자명·소속·이메일·교신저자 (현재 `[저자명 입력]` 등으로 비워 둠)
3. 영문 저자명·소속
4. 그림 2·3의 화면 캡처는 원본 쪽 이미지에서 잘라낸 것이라 해상도가 낮다. 원본 캡처 파일이 있으면 교체하는 편이 좋다.
5. 참고문헌 4건은 원본 그대로 옮겼다. 원문 대조는 하지 않았다.
