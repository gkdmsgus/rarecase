# Clinical Checkpoint 시연 영상 시나리오

작성 2026-10-16. 기준: 최종 논문(`Clinical_Checkpoint_paper_final_v2`)의 학습 흐름(그림 2)과 화면(그림 3·4).
목표 길이 약 2분 30초. 화면 녹화 + 내레이션(자막으로 대체 가능).

> 촬영 대상: 저장소의 Clinical Checkpoint 모드 (`npm run dev` 후 http://127.0.0.1:5173/#cc, 2026-10-16 구현).
> 문진 예시 질문은 증례 CC-001(`server/cc/case-headache.js`)의 사실 목록에 맞춰 두었다. 증례 내용은 의학 검수 전이다.

## 촬영 전 준비
- 브라우저 창 1920×1080, 확대 100 %, 북마크바·알림 끄기
- 첫 화면은 `#cc` 주소로 바로 연다 (로그인 없음)
- 증례: 초기 시나리오인 **급성 비외상성 두통** 1건
- 화면에 "합성 교육용 이미지 · 진단용이 아닙니다"와 SYNTHETIC 표시가 보이는지 확인 (CT는 도식 그림임을 영상에서 말한다)
- 마우스 커서 강조(클릭 표시) 켜기

## 컷 4 문진 예시 질문
앱 증례 데이터와 맞는 것만 쓴다. 의학 내용은 검수 전이므로 영상에서 "정답"처럼 강조하지 않는다.
- "두통이 언제부터 어떻게 시작됐나요?"
- "지금까지 겪은 두통 중에 얼마나 심한가요?" ("비교하면 어떤가요?"처럼 묻으면 증례 사실과 맞지 않아 "모르겠어요"로 답한다)
- "토하거나 목이 뻣뻣한 느낌이 있나요?" (한 번에 두 가지를 물으면 두 답을 함께 한다)
- "최근에 머리를 다치신 적이 있나요?"

## 찍을 때 피할 것
- 실제 환자 정보나 실제 의료영상을 화면에 띄우지 않는다
- 개발자 도구, 터미널, API 키가 보이는 창을 녹화하지 않는다
- AI 응답을 기다리는 긴 대기 구간은 편집에서 자른다
